Set up your transcription model

This extension does not include an AI model. It uses a Whisper model that you install on this computer, so audio never leaves it.

  1. Install Python 3.11 or newer.
  2. In the transcribing-chrome-extension folder, run .\install.ps1 in PowerShell and choose a model.
  3. Click Check again.
